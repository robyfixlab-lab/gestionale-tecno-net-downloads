# Gestionale Tecno-Net — Downloads

Repository pubblico dedicato esclusivamente alla distribuzione dell'installatore Windows e dei file richiesti per gli aggiornamenti automatici del Gestionale Tecno-Net.

- **Scarica l'ultima versione Windows:** [Apri la pagina delle release](https://github.com/robyfixlab-lab/gestionale-tecno-net-downloads/releases/tag/latest)

Questo repository non contiene il codice sorgente del gestionale, credenziali, database o dati dei clienti. Il sistema online continua a usare Vercel e Supabase.
